API keys

A key lets a program act for this garden. Give each program its own key and only the scopes it needs. Leaf shows a key once, when you make it, and keeps only a fingerprint.

What it may do

Copy this key now. Leaf will not show it again.

    Each key is limited per hour, per day and for calls that use Leaf's models. A garden can have 5 keys.

    Home Assistant: soil moisture

    A fresh reading (12 hours) replaces Leaf's weather-based watering estimate for that plant. Below the dry mark (30 % unless you set dry_below) Leaf asks you to water; at or above it, no water is needed. Make a key with the readings scope, then add this to Home Assistant. The example follows Home Assistant's documented rest_command format; Leaf has tested the web call, not a live Home Assistant.
